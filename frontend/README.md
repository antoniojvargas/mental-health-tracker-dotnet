# Frontend

Aplicación de interfaz de usuario del Mental Health Tracker.

Estructura planificada:

```
frontend/
├── src/            # Código fuente (Vue 3 + Vite)
├── public/         # Assets estáticos
├── tailwind.config.*  # Configuración de Tailwind CSS
└── package.json    # Dependencias y scripts
```

Stack previsto: Vue 3, Vite y Tailwind CSS.
